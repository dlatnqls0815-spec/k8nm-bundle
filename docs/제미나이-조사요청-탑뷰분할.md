# 조사 요청: K8(GL3) 젠5W 헤드유닛에서 탑뷰를 ccNC처럼 분할 화면에 "축소해서" 넣을 수 있나

## 목표
ccNC(신형 내비)처럼 왼쪽은 내비(16:9, 1280×720), 오른쪽 640×720 칸에 어라운드뷰 탑뷰가 "잘리지 않고 비율 맞게 축소되어" 나오게 하고 싶다.

## 지금까지 확인된 사실 (2026-11-19, 실차)
- 헤드유닛: 기아 K8 GL3, 젠5W(Android 4.4, Telechips 계열 칩), 화면 1920×720. 루팅(네메시스) + 서개모 앱 주입(앱 프로세스 후킹) 가능.
- 어라운드뷰 영상은 안드로이드 창이 아니라 하드웨어 오버레이 층으로 모든 창 아래에 그려진다. 카메라 앱 창(`AvmCamera`, 형식 2035)은 투명 구멍 역할.
- 카메라 창 크기를 640×720으로 줄이면 영상이 "잘려서" 보인다(축소가 아님). 위·아래 자르기는 됐다.
- 시도했지만 축소가 안 된 것:
  - 카메라 앱의 SurfaceView 크기 변경 → 잘림만, 축소 없음.
  - V4L2 `VIDIOC_S_CROP` → 받아들여지지만 화면 변화 없음.
  - 미리보기 오버레이 크기 조정 → 축소 안 됨.
- 영상 위치·크기는 어라운드뷰 제어기(SVM ECU)가 보내는 화면 배치(보기 번호 2, 3, 21, 22, 23 등)로 정해지는 것으로 보인다. 헤드유닛은 받은 영상을 그대로 겹쳐 그린다.
- 순정에도 "카메라와 분할화면 같이 보기" 경로가 있다(`PgsManager.isDisplaySSWithCamera`, "WIDE DRVM" 관련). 하지만 이 차 설정에서는 false.

## 알아봐 줬으면 하는 것
1. 젠5W/Telechips(TCC) 헤드유닛에서 카메라(LVDS/디지털 영상) 오버레이를 소프트웨어로 축소·이동하는 방법: `/dev/overlay`, `tcc_vioc`, `tccfb` ioctl, 영상 경로(wmixer, scaler) 설정 등.
2. 현대·기아 젠5W에서 SVM 영상을 분할(오른쪽 칸)로 보여 주는 순정 사양이 있는 차종이 있는지(예: "DRVM", "SVM split view", "Wide DRVM"), 그 차종에서 어떤 설정값(차량 사양 코드, `Svm Typ2`, `CameraType`, `isDisplaySSWithCamera`)이 다른지.
3. SVM ECU에 "분할용 작은 탑뷰" 배치를 요청하는 CAN/마이컴 명령이 있는지(있다면 위험도 포함).
4. 영상 프레임을 소프트웨어로 받아서(`/dev/videoN` 캡처) 직접 축소해 그리는 방식이 이 하드웨어에서 현실적인지(지연, CPU).
5. ccNC(신형) 헤드유닛은 같은 SVM으로 어떻게 분할 탑뷰를 하는지(헤드유닛이 축소하는지, SVM이 작은 화면을 보내는지).

## 제약
- 차량에 위험한 CAN 송신은 하지 않는다. 화면 표시만 바꾸는 방법 우선.
- 답변에는 근거(문서·코드·포럼 출처)와 "확인된 것/추측"을 나눠 달라.
